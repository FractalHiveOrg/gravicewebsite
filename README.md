# Gravice Solutions

Marketing site for [gravicesolutions.com](https://gravicesolutions.com), built from the Gravice Brand Identity (P0) Figma system.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Interactive Gravity Mirror (canvas) derived from the brand symbol

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Local development server |
| `npm run build` | Production build         |
| `npm run start` | Serve production build   |

## Structure

- `src/app/page.tsx` — Home (Figma Website / Home Desktop)
- `src/components/GravityMirror.tsx` — Cursor-tracking convex lattice
- `src/app/demo/page.tsx` — Demo request form
- `PRODUCT.md` — Product context for design work
- `.cursor/skills/impeccable` — Impeccable design skill (project install)
